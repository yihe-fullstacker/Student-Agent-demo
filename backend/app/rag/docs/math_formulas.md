# 考研数学核心考点与解题框架

## 极限、微分与中值定理
函数极限计算是高等数学的基石，常用方法包括等价无穷小替换（注意加减法慎用）、洛必达法则、泰勒展开与夹逼准则。中值定理证明题常见辅助函数构造方法需结合罗尔定理、拉格朗日中值定理与柯西中值定理反复演练。

## 积分、级数与微分方程
一元与多元函数积分需熟练掌握换元法、分部积分、二重积分极坐标转换以及数学一特有的曲线曲面积分（格林公式、高斯公式、斯托克斯公式）。无穷级数重点训练正项级数收敛判别与幂级数收敛域及和函数求解。

## 线性代数与概率统计
线性代数各章节联系极强，核心围绕矩阵秩、线性方程组解的结构、特征值与特征向量、相似对角化与二次型展开。概率论重点掌握常见分布的数字特征、大数定律与中心极限定理以及最大似然估计。
