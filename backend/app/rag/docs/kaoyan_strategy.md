# 考研备考周期规划与择校指南

## 三阶段备考节奏
考研全周期通常分为三个阶段：基础阶段（梳理考纲教材与基础例题，重点攻克数学与英语长难句）、强化阶段（专题刷题、建立错题本并启动专业课与政治选择题）、冲刺阶段（全真限时套卷模拟、政治主观题背诵与错题二次清零）。

## 错题复盘与动态调整原则
当连续 3 天出现进度落后或某一知识点连续出错达到阈值时，应果断触发计划动态调整，压缩低优先级泛读任务，将每日黄金时间倾斜给高权重薄弱知识点。

## 择校与志愿梯度策略
择校应综合考量院校地域、往年复试分数线、报录比、专业课是否统考（如 408）及自身当前基础，按照“冲刺、稳妥、保底”建立三档备选清单，避免盲目追高导致复试落榜。
