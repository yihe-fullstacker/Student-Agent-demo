# 计算机专业基础 408 核心知识地图

## 数据结构高频考点
数据结构重点考查线性表、栈与队列、树与二叉树（遍历、线索二叉树、哈夫曼树、并查集）、图论（DFS/BFS、最小生成树 Prim/Kruskal、最短路径 Dijkstra/Floyd、拓扑排序）以及查找（B树、散列表）与内部排序时间空间复杂度比较。

## 计算机组成原理与操作系统
计组核心难点包括定点/浮点数表示（IEEE 754）、Cache 与主存地址映射与替换算法、指令流水线冒险及冲突处理。操作系统高频大题围绕进程同步与互斥（信号量 PV 操作）、死锁条件与银行家算法、虚拟内存页面置换算法（LRU/Clock）及磁盘调度展开。

## 计算机网络核心协议
计算机网络按五层参考模型复习，重点突破数据链路层差错控制与 CSMA/CD、网络层 IP 子网划分与 CIDR 及路由协议（RIP/OSPF）、传输层 TCP 三次握手四次挥手、滑动窗口与拥塞控制算法。
