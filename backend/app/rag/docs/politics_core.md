# 考研政治核心考点速览

## 马克思主义基本原理（马原）
马原是考研政治中理解难度最高的部分，客观题常考唯物论、辩证法与认识论的概念辨析，分析题主要集中在唯物辩证法（矛盾分析法、联系与发展）和认识论（实践与认识的辩证关系）。复习时应优先梳理概念前提条件与对立统一规律。

## 毛中特与新思想
该部分分值占比最高，重点把握中国特色社会主义理论体系的形成脉络、新发展理念、中国式现代化与高质量发展主线。选择题常结合当年重大会议公报考查精准表述，需注意区分“根本动力”“首要任务”“核心支撑”等关键词。

## 史纲与思修
中国近现代史纲要建议按时间轴记忆重大历史事件与会议的意义；思想道德与法治侧重社会主义核心价值观、法治思维与道德修养，分析题通常与材料结合紧密。
